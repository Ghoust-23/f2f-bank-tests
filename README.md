# F2F Bank — E2E Tests

End-to-end тесты для приложения F2F Bank, написанные с использованием Playwright и TypeScript.

## Запуск приложения

### Требования

Для запуска приложения необходимы:

- Docker Desktop
- Docker Compose v2+
- Node.js 18+
- Git

### Запуск

1. Запустить Docker Desktop.

2. В корневой директории проекта выполнить:

```bash
docker compose up -d --build
```

3. После запуска контейнеров приложение будет доступно по адресу:

`http://localhost`

### Остановка приложения

Для остановки приложения:

```bash
docker compose down
```

Для остановки приложения с удалением данных из базы:

```bash
docker compose down -v
```

## Запуск автотестов

Перед первым запуском установить зависимости:

```bash
npm install
```

Установить браузеры Playwright:

```bash
npx playwright install
```

Запуск всех тестов:

```bash
npx playwright test
```

Запуск тестов в UI-режиме:

```bash
npx playwright test --ui
```

Просмотр HTML-отчёта после выполнения тестов:

```bash
npx playwright show-report
```
